Pada percobaan Build a Switch and Router Network ini dilakukan kegiatan membangun jaringan dasar menggunakan router, switch, dan dua PC. Langkah-langkahnya meliputi menyusun topologi sesuai diagram, menghubungkan perangkat dengan kabel, serta mengonfigurasi alamat IP pada setiap antarmuka perangkat. Setelah konfigurasi selesai, dilakukan pengujian konektivitas antar-PC menggunakan perintah ping untuk memastikan komunikasi jaringan berjalan baik. Selain itu, percobaan ini juga melatih penggunaan perintah Cisco IOS seperti show ip route, show interface, dan show ip interface brief untuk menampilkan informasi konfigurasi dan status jaringan. Tujuan akhirnya adalah memahami proses konfigurasi jaringan serta cara memverifikasi dan memantau konektivitas antarperangkat.
